
# Codex Project Rules
## Working Context
- Use GPT-5.5 with medium reasoning by default.
- Use high reasoning for hard debugging, architecture decisions, or visual quality reviews.
- Start substantial work by clarifying goal / context / constraints / done criteria.

## Implementation Style
- Keep edits focused and easy to review.
- Prefer existing project patterns once the codebase has them.
- Avoid unrelated refactors and avoid changing user-provided content unless requested.
- Use TypeScript and Tailwind CSS consistently.

## UI Quality Bar
- Prioritize professional portfolio quality for internship recruiters.
- Optimize for internship credibility, not flashy decoration.
- Make layouts responsive and verify that text does not overlap or spill out of buttons, cards, or sections.
- Use real links and resume assets where available.

## Verification
- Before saying work is complete, run lint/build and the available project checks.
- For UI work, inspect the page in a browser at desktop and mobile widths.
- If a check cannot be run, clearly explain why.
